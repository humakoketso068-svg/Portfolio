# Hey, I'm Koketso 👋

This is my personal portfolio site — built to introduce myself, show what
I'm learning, and give people an easy way to reach me.

## Who I am

I'm a **BCom Information Systems** student at the **University of
Johannesburg**, working toward becoming a **Data Engineer**. I'm interested
in how data actually moves — from messy raw files to clean, reliable systems
that people can build decisions on. Outside of my coursework I'm sharpening
my programming across both application and web development, because I
believe good data infrastructure starts with solid software fundamentals.

## What's on the site

- **Hero** — my name, a short intro, and a photo of me
- **About** — a bit more on my background and where I'm headed
- **Skills** — the tools I'm currently working with: C#, Python, HTML, CSS,
  and JavaScript
- **Projects** — still filling this in as I finish things worth showing
- **Contact** — the best ways to reach me

## Built with

Just plain HTML and CSS — no frameworks, no build tools, nothing fancy.
I wanted it simple and easy for me to edit and understand.

- Fonts: Zilla Slab, IBM Plex Mono, Work Sans (via Google Fonts)
- Responsive, so it works on mobile too

## Files

```
.
├── index.html    # the site itself
├── photo.jpg     # my photo used in the hero section
└── README.md     # you're reading it
```

`photo.jpg` needs to stay in the same folder as `index.html` — the page
links to it by filename, so if one moves without the other, the photo won't
show up.

## Running it locally

No setup needed — just open `index.html` in a browser.

Or, if I want to serve it properly:

```bash
python -m http.server 8000
```

then visit `http://localhost:8000`.

## How I deployed it (GitHub Pages)

1. Pushed everything to a GitHub repo
2. Went to **Settings → Pages**
3. Set the source to the `main` branch, root folder
4. GitHub gave me a live link at `https://humakoketso068-svg.github.io/`
